## 📌 Overview

**Plant-Cure** is a full-stack web application that lets a user upload a photo of a plant leaf and instantly get the detected disease, together with **treatment and prevention advice generated by AI**.

Plant diseases cause major agricultural losses, and identifying them usually takes an expert. Plant-Cure makes the diagnosis accessible to everyone, in seconds.

## ✨ Features

- 📷 Upload a leaf photo from the web interface
- 🧠 Disease detection across **38 classes** (including healthy plants)
- 🤖 Treatment and prevention recommendations generated with the OpenAI API
- 🕘 History of past diagnoses
- 🧪 Three separate environments: `dev`, `test` and `prod`

## 🏗️ Architecture

The project is made of three independent applications, each running in its own Docker container.

| Application | Role | Technologies |
|---|---|---|
| `frontend` | User interface: image upload, diagnosis and history display | HTML, CSS, JavaScript, Nginx |
| `backend` | API: orchestration, diagnosis history, recommendations | FastAPI, Python, OpenAI API |
| `model_service` | Disease prediction from the image | TensorFlow, Keras |

```
User → Frontend (Nginx) → Backend (FastAPI) → Model Service (TensorFlow)
                                  │
                                  └──→ OpenAI API (recommendations)
```

1. The user sends an image through the frontend.
2. The backend forwards the image to the model service.
3. The CNN returns the predicted disease class.
4. The backend asks OpenAI for treatment and prevention advice.
5. The result is shown to the user and saved in the history.

## 🧠 Deep Learning Model

| Item | Detail |
|---|---|
| Dataset | PlantVillage (color images) |
| Classes | 38 |
| Architecture | 4 × Conv2D + MaxPooling blocks, Dense(512) + Dropout(0.5), Dense(38) + Softmax |
| Validation accuracy | approximately 89 to 90 % |
| Framework | TensorFlow / Keras |
| File | `model/plant_disease_prediction_model.keras` (stored with Git LFS) |

## 🚀 Getting Started

### Prerequisites
- Docker and Docker Compose
- Git LFS
- An OpenAI API key

### 1. Clone the repository

```bash
git lfs install
git clone https://github.com/nourelhoudaachour2/Plant-Cure.git
cd Plant-Cure
```

### 2. Configure the environment

Create a `.env` file at the root (it is not versioned, for security reasons):

```
OPENAI_API_KEY=your_openai_key
```

### 3. Run the application

```bash
docker-compose up --build
```
